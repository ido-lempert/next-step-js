🚀 NextStep SDK - Quick Start

This page demonstrates how to integrate the NextStep SDK into your website.

1. Auto-Initialization (Recommended)

Add this script tag to your HTML:

<script src="http://localhost:3333/cdn/nextstep.min.js" data-project-id="your-project-id" data-environment="development" data-debug="true" ></script>

The SDK will automatically initialize when the page loads.

2. Manual Initialization (Alternative)

Initialize programmatically:

<script src="http://localhost:3333/cdn/nextstep.min.js"></script> <script> NextStep.init({ projectId: 'your-project-id', environment: 'development', debug: true, onReady: () => { console.log('NextStep SDK ready!'); }, onError: (error) => { console.error('NextStep SDK error:', error); } }); </script>

4. API Reference

Configuration Options

{ projectId: string; // Required: Your project ID apiKey?: string; // Optional: API key for authentication environment?: string; // Optional: 'development' | 'staging' | 'production' apiUrl?: string; // Optional: Custom API URL debug?: boolean; // Optional: Enable debug logging onReady?: () => void; // Optional: Callback when initialized onError?: (error) => void; // Optional: Callback on error }

SDK Methods

// Initialize the SDK await NextStep.init(options); // Check initialization status NextStep.isInitialized(); // Returns boolean // Get all scripts NextStep.getScripts(); // Returns Script[] // Get specific script NextStep.getScript(scriptId); // Returns Script | undefined // Start a walkthrough await NextStep.startWalkthrough(scriptId, config); // Start a modal await NextStep.startModal(scriptId, config); // Clean up NextStep.destroy();

5. Integration Examples

React Integration

import { useEffect } from 'react'; function App() { useEffect(() => { if (window.NextStep) { window.NextStep.init({ projectId: 'your-project-id', onReady: () => console.log('SDK ready'), }); } }, []); return <div>Your app</div>; }

Vue Integration

export default { mounted() { if (window.NextStep) { window.NextStep.init({ projectId: 'your-project-id', onReady: () => console.log('SDK ready'), }); } } }
