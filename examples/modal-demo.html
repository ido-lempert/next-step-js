Next-Step Modal Component

Interactive training modals for your web application

Implementation Example

import { startModal } from '@next-step/sdk';

const script = {
  id: 'welcome-tour',
  productId: 'my-app',
  name: 'Welcome Tour',
  type: 'modal',
  status: 'published',
  steps: [
    {
      id: 'step-1',
      scriptId: 'welcome-tour',
      orderIndex: 0,
      title: 'Welcome!',
      description: 'Welcome to our app',
      imageUrl: 'https://example.com/welcome.png'
    }
  ]
};

await startModal(script);

Features

  • Shadow DOM for style isolation
  • Keyboard navigation (arrows, ESC)
  • "Don't show again" functionality
  • Responsive design (mobile & desktop)
  • Image support with lazy loading
  • Analytics tracking
  • Focus trap for accessibility
